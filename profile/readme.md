## 🛠️ Troubleshooting

**Trainer not working?**
- Run as Administrator
- Disable your antivirus (or add an exception)
- Make sure the game is running in **Windowed** or **Borderless** mode

**Game crashes?**
- Turn off Instant Catch and try again
